# Omnis Desktop - v2.2.11 Release (Setup & Patch Info)

## Release Metadata
- **Version**: 2.2.11
- **Build Status**: Nexus / Stable Release
- **Target OS**: Windows (nsis)
- **Release Date**: 2026-04-30

## Critical Updates & Fixes

### 1. Salestrack: Robust Data Sanitization
- **Fixed "Invalid or unexpected token" Error**: Resolved critical JavaScript crashes in the dashboard caused by unescaped double quotes (`"`) in customer and machine names. Implemented an `escapeJs` sanitization pattern across inline event handlers to ensure UI stability.
- **Improved Display Rendering**: Stripped literal double quotes from display-only fields (Customer and Machine names) in both the Order List and the Edit Order Details modal, achieving a cleaner, more professional UI without losing database connectivity.

### 2. Salestrack: Advanced Machine Order Management
- **Full Machine Editing Capabilities**: The "Machines" table in the Edit Order Details modal has been upgraded from static read-only text to a fully interactive suite of inputs. Users can now edit the Machine/Item name, Serial Number, Quantity, and Target Date natively.
- **Machine Deletion Protocol**: Users can now instantly delete existing machines from an order via a new 'remove' (`×`) button in the modal. Deletions are processed securely on the backend when changes are saved, purging the child record permanently.
- **Live Search Auto-suggest**: Implemented a blazing fast, real-time autocomplete function for the Machine/Item input fields. Connected directly to the Frappe backend, it queries the master item database and displays suggestions (including Item Name, Group, and Brand) automatically as the user types 2 or more characters.

## Deployment Instructions

### A. Backend (Frappe Server)
> **IMPORTANT**: This patch requires a backend deployment. The desktop app cannot save new machine edits or process deletions without the updated `omnis_dashboard.py` file running on the live server.

1. Upload the updated `omnis_dashboard.py` from the local workspace to your Frappe server.
2. Place it in the appropriate backend directory (e.g., `~/frappe-bench/apps/powerstar_salestrack/powerstar_salestrack/` or similar depending on the app name).
3. Restart the bench to apply Python changes:
   ```bash
   bench restart
   # or
   sudo supervisorctl restart all
   ```

### B. Desktop Client (Build Installer)
1. Ensure all dependencies are installed:
   ```bash
   npm install
   ```
2. Build the new installer:
   ```bash
   npm run build
   ```
3. The new installer will be named `Omnis_Setup_2.2.11.exe` in the `dist/` folder.

### C. GitHub Release
1. Commit and push the latest code to the `master`/`main` branch.
2. Create a new release tagged `v2.2.11` on GitHub.
3. Upload `Omnis_Setup_2.2.11.exe` and `latest.yml` from the `dist/` folder to the release artifacts.
4. Existing users will receive the update automatically via the built-in auto-updater once they launch the application.

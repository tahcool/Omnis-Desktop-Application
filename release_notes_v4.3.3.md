# Omnis Desktop Application v4.3.3

## Release Notes
- **Stock Pipeline Enhancements:** Refactored table sorting logic so that columns are now fully sortable globally across all stock phase tables (e.g. In Transit, Enroute From Beira, etc.) without losing context.
- **UI Improvements:** Fixed an issue where grid headers were invisible due to conflicting background styling. They now correctly inherit the system's maroon gradient.
- **Auto-Updater Fixes:** Resolved an issue where the background download progress was not emitting correctly to the UI. The progress bar will now correctly report download statistics during auto-updates.
- **Minor Cleanups:** Removed legacy debug toggles and updated internal tutorial tracking for sales system group overviews.

# Omnis Setup Summary - v2.2.12 NEXUS

This version introduces significant refinements to the OEM Management Reports and stabilizes the internal WhatsApp integration for improved operational connectivity.

## 📊 Report Refinements (OEM & Sales)
- **Categorical Aggregation**: Quotes and Sales are now grouped by machine category (Dozer, Excavator, etc.) for a cleaner management overview.
- **YTD Consistency**: Decoupled Year-to-Date figures from period filters. YTD columns now consistently display full-year performance (Jan 1st – Date) regardless of the selected month.
- **Detail Filtering**: Breakdown and detail tabs (Quotes/Sales) now correctly isolate records for the selected period (e.g., viewing only April records when April is filtered).
- **Navigation Cleanup**: Moved "Sales" from the Reports menu to the **Operations** dropdown to better reflect its status as an operational list.
- **Label Updates**: Renamed "Tracking" to **Order Tracking** and "Stock" to **Stock Pipeline** for improved clarity.

## 📱 WhatsApp Connectivity Stabilization
- **Remote Versioning**: Switched to a remote WhatsApp Web version provider to bypass "outdated browser" errors.
- **Enhanced Browser Mode**: Implemented **Headless: New** mode with improved stability flags for better compatibility with Windows environments.
- **Granular Diagnostics**: Added a background debug log (`whatsapp_debug.log`) and more descriptive error reporting to the UI.

## 🛠️ Repository & CI/CD
- **GitHub Integration**: Added professional `README.md` and `LICENSE`.
- **Automated Releases**: Configured GitHub Actions workflow for automated Electron builds and releases via tags.
- **Version Bump**: Official transition to **v2.2.12 NEXUS**.

---
**Deployment Note**: To activate the new WhatsApp connectivity engine, a full application restart is required after installation.

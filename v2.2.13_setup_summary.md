# Release Notes: Omnis v2.2.13 NEXUS (Hotfix)

**Release Date:** May 4, 2026  
**Version:** 2.2.13 NEXUS  

---

## 🔧 Critical Fixes
*   **Production Permission Fix**: Resolved an `EPERM` error that prevented the application from initializing WhatsApp on computers where the app was installed in `C:\Program Files`.
    *   Diagnostic logs are now safely stored in the user's `AppData` folder instead of the restricted installation directory.
*   **Stability Improvement**: Ensured that the application can correctly initialize background processes even without administrative privileges.

---

## 📝 Installation
This is a high-priority hotfix. If you encountered an "Operation Not Permitted" error when linking WhatsApp in v2.2.12, please upgrade to **v2.2.13** immediately.
